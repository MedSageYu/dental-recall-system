📘 使用手册

快速开始

  1. 安装 Ollama：访问 ollama.com 下载安装，终端运行 ollama pull qwen3.5:2b
  2. 上传教材：点击书库页「+ 上传 PDF」，选择口腔医学 PDF，设置背诵天数
  3. 开始背诵：点击书 → 点击「开始学习」→ 逐题背诵 → 看到 AI 评分 → 自动下一题
  4. 查看进度：日历页查看每日学习情况，统计页查看整体掌握度

学习流程

系统基于 艾宾浩斯遗忘曲线 安排复习。每天背诵内容包含：

  • 📌 新学：今天计划学习的新知识点
  • 🔄 复习：之前学过但即将遗忘的知识点
  • ↩️ 顺延：昨天未完成的内容自动顺延到今天

评分说明

每个知识点评分为 5 个维度的加权总分：

  • 🎯 关键考点覆盖（30%）：核心考点是否提到
  • 📝 知识完整性（20%）：是否覆盖主要知识点
  • ✅ 表述准确性（20%）：关键概念是否正确
  • 🔗 逻辑条理性（15%）：是否有条理
  • 💡 理解深度（15%）：是否展现深入理解

数据安全

  • 所有数据存储在本地 SQLite 数据库
  • 每次启动自动备份，关机优雅保存
  • 背诵原文与 AI 分析分开存储，互不覆盖
  • 原文同步备份到 data/recitations/ 目录

推荐配置

  • AI 模型：Ollama + qwen3.5:2b（2.7GB，轻量高效）
  • 备份模型：qwen2.5:7b（更精准但更慢）
  • 端口：默认 8088，可通过命令行参数修改

命令行

# 启动（默认端口 8088）
python3 app.py

# 指定端口
python3 app.py 9000

# 安全退出
# 按 Ctrl+C，自动保存所有数据
