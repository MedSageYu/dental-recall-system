# 🦷 口腔医学考研带背系统

基于艾宾浩斯遗忘曲线的智能背诵管理系统。支持 PDF 教材上传、OCR 自动识别、智能切题、间隔复习、逐字评分、进度追踪，全程本地运行，无需联网。

---

## ✨ 核心功能一览

| 功能 | 说明 |
|------|------|
| 📄 PDF 上传 | 支持文字版和扫描版 PDF，自动 OCR 识别中文 |
| ✂️ 智能切题 | 正则自动按编号切分知识点，无需手动整理 |
| 📚 书库管理 | 多本书并行管理，支持重命名、删除、重新规划 |
| 📖 一键学习 | 开始 → 逐题背诵 → 评分 → 自动下一题 → 完成总结 |
| 🎯 逐字评分 | 字符级精确匹配，不靠 AI 猜测，输入"一"就该 0 分 |
| 🔁 艾宾浩斯复习 | 自动安排复习间隔（1→2→4→7→15→30→60→120 天） |
| 📅 学习日历 | 每日学习数据可视化，点击查看当日详情 |
| 📊 统计面板 | 总知识点、已掌握、今日学习量、背诵字数 |
| 💾 数据安全 | WAL 模式 + 自动备份 + 原文与评分分离存储 |
| 🖥️ macOS 原生 | 提供 .app 启动器，双击即开 |

## 📦 安装指南

### 第 1 步：安装 Python 依赖

```bash
# 克隆项目
git clone https://github.com/你的用户名/dental-recall-system.git
cd dental-recall-system

# 安装依赖
pip3 install -r requirements.txt
```

> **依赖说明：**
> - `PyMuPDF` — PDF 文字提取（文字版 PDF 直接读取）
> - `rapidocr-onnxruntime` — 中文 OCR 引擎（扫描版 PDF 自动识别）
> - 两个包加起来约 200MB，首次安装需要几分钟

### 第 2 步（可选）：安装 Ollama AI 模型

> ⚠️ **Ollama 是可选的。** 系统核心功能（上传、切题、背诵、评分）不依赖 AI。Ollama 仅用于高级功能（每日总结、薄弱点分析）。

```bash
# 1. 安装 Ollama
# macOS: 访问 https://ollama.com 下载安装
# Linux: curl -fsSL https://ollama.com/install.sh | sh

# 2. 拉取模型（约 2.7GB）
ollama pull qwen3.5:2b

# 3. 验证
ollama list
# 应显示 qwen3.5:2b
```

### 第 3 步：启动系统

```bash
# 方式一：命令行启动
python3 app.py          # 默认端口 8088
python3 app.py 9000     # 自定义端口

# 方式二：macOS 双击启动
# 双击 ~/Applications/口腔考研带背.app
```

### 第 4 步：打开浏览器

访问 **http://localhost:8088**

## 📖 使用教程

### 一、上传教材（书库页）

1. 点击书库页右上角 **「+ 上传 PDF」** 按钮
2. 选择口腔医学 PDF 文件（支持文字版和扫描版）
3. 设置**背诵天数**（例如 30 天 = 把所有知识点均匀分配到 30 天）
4. 点击 **「上传并解析」**
5. 等待处理完成（扫描版 PDF 需要 OCR，每页约 3-4 秒）

**上传过程中你会看到：**
- 📖 正在识别第 X/Y 页 — OCR 文字识别进度
- 🧠 AI 正在分析 — 知识点切分进度
- ✅ 解析完成 — 上传成功，知识点已入库

**支持的 PDF 类型：**
- ✅ 文字版 PDF（直接提取文字，瞬间完成）
- ✅ 扫描版 PDF（自动 OCR 识别中文，每页 3-4 秒）
- ✅ 混合版 PDF（先尝试文字提取，失败则自动降级 OCR）

### 二、书库管理（书库页）

书库页显示所有已上传的教材，每本书显示：
- **书名** — 点击可进入学习
- **知识点总数** — 该书包含多少个知识点
- **今日计划** — 今天需要学习/复习的知识点数
- **掌握率** — 已掌握知识点占比

**操作按钮：**
- ✏️ **重命名** — 修改书名
- 🔄 **重新规划** — 修改背诵天数，重新分配每日计划
- 🗑️ **删除** — 删除该书及所有学习记录（不可恢复）

### 三、开始学习（背诵页）

1. 在背诵页选择要学习的书
2. 点击 **「🚀 开始学习」**
3. 系统自动进入**一键到底**学习流程：

**每道题的学习流程：**

```
┌─────────────────────────────────────┐
│  📋 显示题目标题（不显示答案！）      │
│                                     │
│  💭 你回忆 → 在输入框默写/口述        │
│                                     │
│  ✅ 点击「提交并继续」                │
│                                     │
│  ⏳ 等待评分（瞬间完成）              │
│                                     │
│  📖 显示标准答案                      │
│  🎯 显示评分结果（5 个维度）          │
│  📝 显示遗漏考点 + 记忆建议           │
│                                     │
│  → 点击「下一个」继续                 │
└─────────────────────────────────────┘
```

**评分维度说明：**

| 维度 | 权重 | 说明 |
|------|------|------|
| 🎯 关键考点覆盖 | 30% | 原文中的 (1)(2)(3) 等子要点是否被提到 |
| 📝 知识完整性 | 20% | 是否覆盖了原文的主要内容 |
| ✅ 表述准确性 | 20% | 关键概念是否表述正确 |
| 🔗 逻辑条理性 | 15% | 背诵是否有条理 |
| 💡 理解深度 | 15% | 是否展现深入理解 |

**评分等级：**
- 🟢 **90+ 优秀** — 掌握扎实
- 🔵 **70-89 良好** — 基本掌握
- 🟡 **55-69 一般** — 需要加强
- 🔴 **<55 不及格** — 需要重新学习

**学习完成后：**
- 显示今日总结（背诵数量、平均分、最高分、最低分）
- 显示各知识点详情（标题、分数、状态）
- 可跳转日历页或返回书库

### 四、艾宾浩斯复习

系统基于**艾宾浩斯遗忘曲线**自动安排复习：

```
学习 → 1天后复习 → 2天后 → 4天后 → 7天后 → 15天后 → 30天后 → 掌握
```

**记忆等级：**
| 等级 | 状态 | 下次复习间隔 |
|------|------|------------|
| 0 | 未学 | — |
| 1 | 刚学 | 1 天 |
| 2 | 初步记住 | 2 天 |
| 3 | 基本记住 | 4 天 |
| 4 | 较好记住 | 7 天 |
| 5 | 完全掌握 | 15 天 |

**每天的学习内容包含：**
- 🆕 **新学** — 今天计划学习的新知识点
- 🔄 **复习** — 之前学过但即将遗忘的知识点
- ↩️ **顺延** — 昨天未完成的内容自动顺延到今天

**答对** → 记忆等级 +1，下次复习间隔翻倍
**答错** → 记忆等级重置为 0，明天重新学习

### 五、学习日历（日历页）

- 每个日期格子显示当日学习量（彩色圆点）
- 颜色深浅表示学习量多少
- **点击任意日期** → 查看当日详细学习记录：
  - 学习了哪些知识点
  - 每个知识点的分数
  - 当日总结报告（如已生成）

### 六、学习统计（统计页）

显示整体学习数据：
- 📊 总知识点数 / 已掌握数 / 学习中数
- 📈 今日学习量（知识点数 + 背诵字数）
- 📉 历史学习趋势

### 七、Ollama AI 功能（可选）

安装 Ollama 后，系统自动启用以下 AI 功能：

| 功能 | 说明 | 触发时机 |
|------|------|---------|
| 📝 每日总结 | AI 根据今日背诵情况生成学习报告 | 每日学习完成时 |
| 💡 薄弱点分析 | AI 分析遗漏考点，给出记忆建议 | 评分时 |
| 🖼️ 图片识别 | 分析口腔图片（需要视觉模型） | 手动上传图片 |

**检查 Ollama 状态：**
- 页面顶部的 Ollama 状态徽章显示当前连接状态
- 🟢 绿色 = 已连接，显示模型名称
- 🔴 红色 = 未连接（不影响核心功能）

## ⚙️ 配置说明

### 端口设置

```bash
python3 app.py          # 默认 8088
python3 app.py 9000     # 自定义端口
```

### 数据安全机制

- **SQLite WAL 模式** — 读写分离，崩溃不丢数据
- **即时提交** — 每条背诵记录立即写入数据库
- **自动备份** — 每次启动自动备份到 `data/backups/`，保留最近 30 个
- **原文分离** — 背诵原文与 AI 评分分开存储，评分失败不影响原文
- **原文备份** — 每次背诵原文同步保存到 `data/recitations/` 目录（txt 格式）
- **优雅关机** — 按 `Ctrl+C` 自动保存所有数据后退出
- **断点续背** — 学习进度实时保存，刷新页面可继续

### 自动收起时间

在设置面板中可调整「自动收起时间」（0.5-10 秒，步长 0.1 秒，默认 1.2 秒）。

## 🔧 常见问题

### Q: 扫描版 PDF 上传后提示"PDF 内容为空"

**原因：** OCR 引擎未安装或安装失败。

**解决：**
```bash
pip3 install rapidocr-onnxruntime
# 如果失败，尝试：
pip3 install rapidocr-onnxruntime --no-cache-dir
```

### Q: Ollama 状态显示红色

**原因：** Ollama 未安装或未启动。

**解决：**
```bash
# 检查 Ollama 是否运行
ollama list

# 如果未安装，访问 https://ollama.com 下载
# 如果已安装但未运行：
ollama serve
```

### Q: 上传 PDF 后切出 0 个知识点

**原因：** PDF 内容格式特殊（如纯图片、无编号格式）。

**解决：**
- 确认 PDF 是文字版或扫描版（纯图片 PDF 需要 OCR）
- 检查 PDF 内容是否有中文文字
- 查看服务器终端输出的错误信息

### Q: 评分结果总是很高/很低

**说明：** 评分基于**字符级精确匹配**，系统会提取原文中的 (1)(2)(3) 等子要点，逐个检查你的背诵是否覆盖。评分结果反映的是**关键考点覆盖率**，不是语义相似度。

### Q: 数据库文件在哪里？

```
data/recall.db          # 主数据库
data/recall.db-wal      # WAL 日志（正常存在）
data/recall.db-shm      # 共享内存文件（正常存在）
```

### Q: 如何备份数据？

```bash
# 方式一：自动备份（每次启动时）
# 备份在 data/backups/ 目录

# 方式二：手动备份
cp data/recall.db data/recall.db.backup

# 方式三：导出原始数据
# 背诵原文在 data/recitations/ 目录，txt 格式
```

### Q: 如何迁移到另一台电脑？

```bash
# 1. 复制整个项目目录
# 2. 复制 data/ 目录（包含数据库和备份）
# 3. 在新电脑上安装依赖
pip3 install -r requirements.txt
# 4. 启动即可，数据库自动迁移 schema
```

## 🛠️ 批量导入

如果你有多个 PDF 文件需要一次性导入：

```bash
# 1. 将 PDF 文件放在 ~/Desktop/课本/ 目录
# 2. 运行批量导入
python3 batch_import.py
```

批量导入会：
- 自动扫描目录下所有 PDF 文件
- OCR 识别 → 正则切题 → 写入数据库
- 跳过已导入的文件（按文件名判断）

## 📋 API 接口

系统提供完整的 REST API，可用于自动化或二次开发：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/books` | GET | 获取所有书籍列表 |
| `/api/upload-pdf` | POST | 上传 PDF（multipart/form-data） |
| `/api/due-topics` | GET | 获取今天需要学习的知识点 |
| `/api/start-session` | POST | 开始学习会话 |
| `/api/study` | POST | 提交背诵答案并获取评分 |
| `/api/end-session` | POST | 结束学习会话 |
| `/api/calendar` | GET | 获取学习日历数据 |
| `/api/stats` | GET | 获取学习统计 |
| `/api/day-summary` | GET | 获取每日总结 |
| `/api/settings` | GET/POST | 获取/更新设置 |
| `/api/update-book` | POST | 更新书籍信息 |
| `/api/delete-book` | POST | 删除书籍 |
| `/api/replan` | POST | 重新规划背诵计划 |
| `/api/ollama-status` | GET | 检查 Ollama 连接状态 |
| `/api/estimate-score` | GET | 预估考研分数 |
| `/api/shutdown-save` | POST | 手动触发数据保存 |
